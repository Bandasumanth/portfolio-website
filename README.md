# 🚀 Sumanth Manu - Premium Portfolio Website

A modern, responsive, and highly interactive personal portfolio website built with React, Node.js, and Tailwind CSS. Designed to showcase professional work, skills, and achievements with premium UI/UX patterns inspired by leading tech companies.

## ✨ Features

### Frontend
- ⚛️ **React + Vite** - Fast development and production builds
- 🎨 **Tailwind CSS** - Utility-first styling with dark/light mode
- ✨ **Framer Motion** - Smooth animations and page transitions
- 📱 **Fully Responsive** - Mobile, Tablet, Desktop optimized
- 🌓 **Dark/Light Mode** - Theme switcher with persistence
- 🎯 **SEO Optimized** - Meta tags, Open Graph, Sitemap
- ♿ **Accessibility** - WCAG compliant
- 🚀 **Performance** - Lazy loading, code splitting, optimized images

### Sections
- 🎭 Hero Section with animated gradient blobs and particles
- 👤 About Me with professional background
- 💻 Skills with animated progress indicators
- 📈 Experience Timeline
- 🎨 Featured Projects with case studies
- 🏆 Achievements & Statistics
- 💬 Testimonials
- 📧 Contact Form with validation
- 📄 Resume Section

### Backend
- 🟢 **Node.js + Express** - RESTful API
- 🗄️ **MySQL** - Database for contact messages
- 📧 **Nodemailer** - Email notifications
- 🔐 **Validation & Security** - Input validation, CORS

### Premium Features
- 🎪 Custom loading screen
- 🖱️ Animated cursor effects
- 📊 Scroll progress bar
- ✍️ Typing animations
- 📜 Scroll reveal animations
- 🎬 Hover micro-interactions
- 🌐 Glassmorphism effects
- 🎨 Premium gradients
- 🔧 Performance optimized

## 🚀 Quick Start

### Prerequisites
- Node.js (v16+)
- npm or yarn
- MySQL

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Bandasumanth/portfolio-website.git
   cd portfolio-website
   ```

2. **Frontend Setup**
   ```bash
   cd frontend
   npm install
   npm run dev
   ```

3. **Backend Setup**
   ```bash
   cd ../backend
   npm install
   cp .env.example .env
   npm start
   ```
